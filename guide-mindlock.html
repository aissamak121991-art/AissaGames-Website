How to play Mindlock

Understand the feedback, learn the seven worlds and crack every code.

In short Mindlock: Color Code Puzzle hides a secret code made of coloured tokens. You build guesses, get feedback after each one, and use logic to find the code before you run out of attempts.

1. About Mindlock

Mindlock is a modern take on the classic code-breaking game. It is built for short sessions of one to four minutes, played in portrait with one thumb. The game has 140 levels in seven worlds, and each world adds a single new twist to the rules so you learn one idea at a time.

2. The goal

Each level has a hidden code of 3 to 6 slots. Every slot holds a coloured token, and in later worlds tokens also have shapes. You must reproduce the code exactly within the number of attempts you are given. When every slot is correct, you win.

3. How a turn works

  1. Tap a colour in the palette to place it in the next empty slot, or drag it into the slot you want.
  2. Tap a filled slot to remove its token, or drag tokens between slots to rearrange them.
  3. When every playable slot is filled, press Check.
  4. Read the feedback, update your reasoning, and make the next guess.

4. Reading the feedback

After each guess you get counts, not a position-by-position answer:

  • Exact: the number of tokens that have the right colour in the right slot.
  • Misplaced: the number of tokens that exist in the code but are in the wrong slot.

On levels with shapes, the feedback also tells you whether a token is perfect, has the right colour but a different shape, or the right shape but a different colour. The history of guesses stays on screen, so you can always look back and check your deductions.

5. The seven worlds

WorldWhat is new
1. SparkThe basics: three slots, exact and misplaced feedback.
2. PulseLonger codes with more colours.
3. PrismShapes join the colours, with their own kinds of feedback.
4. EchoThe same token can appear more than once in the code.
5. ShadowOne shadowed slot is left out of the evaluation, and you must reason around it.
6. FluxTwo secret tokens swap places every few attempts, and the swap is announced.
7. ZeroA timer is added, and rules from earlier worlds are mixed together.

Each world ramps up in difficulty, and the last level of every world is a boss level. A level earns up to three stars depending on how few attempts you needed.

6. Daily challenge

Every day brings a new puzzle that is the same for all players. You get a limited number of attempts, and you can keep a streak by solving it day after day. When you finish, you can share a result made of coloured dots that shows how you did without revealing the answer.

7. Power-ups

  • Reveal shows the token for one hidden slot.
  • Eliminate tells you one colour that is not in the code.
  • Extra attempts adds attempts when you are close to running out.

Use them to confirm a hunch, not as a first resort, since solving by logic is what the game is about.

8. The Vaults

Mindlock also has a collection feature called the Vaults. As you progress, you unlock treasures that you can look at as interactive 3D objects, turning them with your finger, and secret vaults hold special puzzles of their own.

9. Strategy: how to crack a code

  1. Start with variety. A first guess that uses several different colours teaches you more than one repeated colour.
  2. Note what each result rules out. If a guess returns no exact and no misplaced, none of its colours are in the code.
  3. Change one thing at a time. Swap two tokens or replace one colour, and compare the feedback with the previous guess to see which change mattered.
  4. Use the history. Before every guess, check that it could still be the answer given all the earlier feedback. A guess that cannot be the answer wastes an attempt.
  5. Adapt to the world. In Echo, allow duplicates. In Shadow, remember one slot is outside the evaluation. In Flux, track the announced swaps.

10. Privacy and terms

This guide only explains how to play. Data collection, advertising, consent choices and your rights are described in the Mindlock Privacy Policy, with the rules for using the game in the Mindlock Terms of Use. Translations are available in Arabic and French. For help, visit Support.
